## Card format (BACKLOG-DETAILED.md)

After the backlog passes its gate, every item before Post-launch gets a card that says what to build and how, so whoever picks it up starts without asking. debate-arch writes them in `phase cards`, in groups; the gate checks every field.

```
### Bnn - <item title>
- What: <the outcome a user or a check sees, 1-2 lines>
- Source: <the item's source: spec NN:Txxx, ADR-NNNN, SDD-n>
- How:
  1. <step, naming the module, path or command>
  2. <step>
- Files: <paths created or changed>
- Interfaces: <endpoint, event, schema or component with its fields, or none>
- Done when:
  - Given <state> When <action> Then <result with a number>
- Test: <automated test: kind, name, what it asserts>
- Risks: <what can go wrong and the way out, or none>
```

## Definition of Ready

- acceptance criterion with a number, source cited, dependencies resolved or listed, estimate up to L, screen design ready when there is UI

## Definition of Done

- acceptance verified and noted, automated test in CI, Empty/Loading/Error states and keyboard focus on the touched screen, final copy, no new error in the log, docs/ADR updated
